# AEGIS — Enterprise Multi-Agent AI Decision Intelligence Platform

Enterprise AI system that converts natural-language business questions
into evidence-grounded executive intelligence using specialized AI agents.

## Key Capabilities

• Stateful multi-agent orchestration using LangGraph
• Dynamic task planning and routing
• SQL intelligence with generated and validated SQL
• RAG over internal enterprise knowledge
• External market research
• Evidence aggregation across agents
• Grounded executive synthesis
• LLM retry and rate-limit handling
• Enterprise intelligence dashboard using Streamlit
